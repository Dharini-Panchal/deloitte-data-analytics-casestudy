# Deloitte Australia - Data Analytics Simulation Case Study

## Project Overview
A comprehensive case study based on the Deloitte Australia Data Analytics Virtual Job Simulation. This project covers data ingestion, dashboard visualization, telemetry breakdown, and forensic technology analytics to solve real-world corporate challenges.

---

## Completed Tasks

### Task 1: Daikibo Telemetry Analysis (Tableau)
* **Goal:** Identified plant downtime bottlenecks across global factory locations using JSON telemetry data.
* **Key Finding:** Concentrated failure in `LaserCutter` equipment at the **Daikibo Shenzhen** facility (~420 mins total downtime).
* **Folder:** [`/task1-telemetry-analysis`](./task1-telemetry-analysis)

### Task 2: Forensic Technology - Gender Pay Equality (Excel)
* **Goal:** Standardized compensation inequality metrics across global roles using multi-tiered risk classification logic.
* **Key Finding:** Categorized all factory roles into Fair, Unfair, and Highly Discriminative risk tiers for targeted HR remediation.
* **Folder:** [`/task2-forensic-equality-analysis`](./task2-forensic-equality-analysis)
