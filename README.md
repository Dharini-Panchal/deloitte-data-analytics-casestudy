# Deloitte Australia - Data Analytics Virtual Internship Case Study

## Project Overview
This repository contains a two-part data analytics case study completed as part of the **Deloitte Australia Data Analytics Job Simulation** via Forage. The project combines telemetry analysis using interactive data visualization with forensic technology analytics for human resources compliance.

---

## Executive Summary & Core Results

| Task | Business Problem | Tool Used | Key Insight / Result | Folder Link |
| :--- | :--- | :--- | :--- | :--- |
| **Task 1: Telemetry & Downtime Analysis** | Identify factory locations and equipment types causing operational breakdowns. | **Tableau** | **Daikibo Shenzhen** experienced the highest downtime (~420 mins), driven almost entirely by failures in **LaserCutter** machinery (~390 mins). | [`/task1-telemetry-analysis`](./task1-telemetry-analysis) |
| **Task 2: Forensic Gender Pay Equality** | Classify company-wide roles into risk tiers based on calculated equality scores (-100 to +100). | **Excel** | Designed nested conditional logic (`IF` + `ABS`) to classify compensation across Fair ($\pm10$), Unfair, and Highly Discriminative ($>\pm20$) risk tiers for audit prioritization. | [`/task2-forensic-equality-analysis`](./task2-forensic-equality-analysis) |

## Technical Skills Demonstrated
* **Data Visualization & Dashboarding:** Tableau Desktop / Public, interactive cross-filtering, metric calculation.
* **Data Transformation & Logic:** Excel advanced conditional logic (`IF`, `ABS`), dataset classification, risk tiering.
* **Business Communication:** Executive findings summaries, root-cause identification, risk mitigation strategies.
